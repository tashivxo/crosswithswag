# Stitch Screen Prompt Pack

Use these prompts with `stitch/DESIGN.md`. Generate desktop first, then mobile variants for Hero and one SWAG poster.

## Global instruction

Create screens for swag., a dark type-led wearable editions brand. Follow `stitch/DESIGN.md` exactly. This is a digital gallery, not ecommerce. No product grids, no cards, no sale language, no generic buttons. Use the four brand colours only.

## Screen 1: Hero / Landing

Create a full-viewport hero screen on Void Black `#0A0A0A`.

Elements:
- Custom swag. wordmark top-left in Muted Sand `#D6D1C4`.
- Small uppercase label `WEARABLE EDITIONS` near the wordmark.
- Massive low-opacity ghost type in the background: `NOTH- / OWE / ING.`
- No CTA, no product image, no explanatory paragraph.

Mood:
Quiet, restrained, fashion-editorial. Let silence carry the brand.

Output:
- Desktop composition.
- Mobile portrait composition.

## Screen 2: Manifesto

Create a full-viewport manifesto screen on Void Black `#0A0A0A` with Muted Sand text.

Copy:

We stopped explaining ourselves a long time ago.

swag. is not a collection. It is not a drop. It is not content.

Each piece exists once - conceived, made, and released into the world as a singular object. The garment. The image. The frame on your wall. All the same thoughts, held in different forms.

We call them wearable editions because that is what they are. Not a product. Not merch. Objects that carry a point of view - made for the people who already know who they are.

We owe nothing to anyone. We occupy the space of those who have already accepted themselves.

This is not for everyone.

It was never meant to be.

- the director.

Composition:
Large body type, not display type. Use generous whitespace and a separate sign-off lockup.

## Screen 3: SWAG Poster - Authentic Expression

Background: Void Black `#0A0A0A`.

Content:

- Massive bleed word: `EXPRESSION`
- Ghost watermark layer: `CROSS / WITH / SWAG`
- Statements:
  - A home for individuals
  - Does not seek permission to exist
  - Speaks to be true, not approved

Output:
- Desktop composition.
