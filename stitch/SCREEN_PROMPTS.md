# SWAG — Stitch Screen Prompts (Copy-Verified)

**Status:** Finalized 6 July 2026. All copy extracted from `lib/copy.ts`. Verified against Marcus sign-off in `cursor.md/marcus-signoff-checklist.md`.

**How to use:**
1. Paste `stitch/DESIGN.md` into Stitch as the design system context.
2. Generate one screen per prompt below (desktop first, 1440×900 or 1920×1080 viewport).
3. Do not paraphrase copy. Use exact strings in quotation marks.
4. Use custom SVG wordmark — do not approximate with a typed font.

**Global instruction (paste once before Screen 1):**

```text
Create screens for swag., a dark type-led wearable editions brand. Follow stitch/DESIGN.md exactly. This is a digital gallery, not ecommerce. No product grids, no cards, no sale language, no generic buttons, no rounded containers, no gradients. Use only these four brand colours: Void Black #0A0A0A, Stone Grey #575D61, Clay #8C5E4A, Sand #D6D1C4. Typeface: Instrument Sans 400 / 500 / 700 only. CTAs are text links only. Let display type bleed off viewport edges intentionally. Quiet, editorial, restrained — not AI SaaS hero, not streetwear sale banner.
```
